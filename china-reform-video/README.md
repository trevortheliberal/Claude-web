# 大潮：中国改革开放简史（1978—2026）

一部约 9 分半钟的 1080p 纪录短片，用动态图文、地图和数据图表讲述 1978 年以来中国改革开放的历程，配有中文旁白、同步字幕和配乐。

成片：`output/大潮-中国改革开放简史.mp4`　字幕：`output/字幕.srt`（画面已内嵌字幕，SRT 供另行使用）

## 结构

| 段落 | 年代 | 内容 |
| --- | --- | --- |
| 序章 | 1978 | 1978 年的中国：GDP 3679 亿元、人均 385 元、城镇化率 17.9%、农村贫困人口 7.7 亿 |
| 第一章 · 破冰 | 1978—1991 | 真理标准讨论与十一届三中全会、小岗村、中美建交、经济特区与沿海开放（地图）、1984 年城市改革、1988—1991 年的曲折 |
| 第二章 · 市场 | 1992—2001 | 南方谈话与十四大、浦东/股市/“下海”/分税制、国企改革与下岗、港澳回归、加入世贸组织 |
| 第三章 · 融入 | 2001—2012 | “世界工厂”、神舟五号与取消农业税、2008 年（汶川地震、北京奥运、金融危机）、成为第二大经济体 |
| 第四章 · 新时代 | 2012—2026 | 全面深化改革与“一带一路”、脱贫攻坚、高铁与航天、新冠疫情、发展中的课题、“十五五”规划 |
| 数说 | 1978—2025 | GDP 曲线；城镇化、进出口、人均预期寿命今昔对比 |

数据来自国家统计局历年统计公报和《改革开放 40 年经济社会发展成就系列报告》、交通运输部、国家卫生健康委员会、世界银行；2025 年数据取自 2026 年 2 月发布的统计公报。

## 修改与重新生成

所有旁白文字、画面文字、数据和镜头编排都在 `script.json` 里：改完后运行

```bash
bash tools/build.sh            # 加 --check 会用语音识别校对旁白有没有读错
```

即可重新生成成片（4 核约 25 分钟）。常用改法：

- **换旁白音色**：`script.json` → `voice.sid`（Kokoro v1.1-zh，3–57 为女声，58–102 为男声），`voice.speed` 调语速。
- **改某句旁白**：改对应场景的 `lines`；字幕和镜头时长会自动跟着旁白长度重新排。
- **预览某一时刻**：`node tools/render.mjs stills 120 245.5`，图片输出到 `build/stills/`。
- **浏览器里实时预览**：在项目根目录起一个静态服务（如 `npx serve .`），打开 `/web/index.html?play`。

## 制作方式

| 环节 | 工具 |
| --- | --- |
| 画面 | `web/` 下的 HTML/CSS/JS，每帧都是时间的纯函数（`window.seek(t)`），用无头 Chromium 逐帧截图 → ffmpeg（H.264） |
| 旁白 | [Kokoro v1.1-zh](https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh)（Apache-2.0）经 sherpa-onnx 离线合成；SenseVoice 识别回读做校对 |
| 配乐 | `tools/music.py` 程序合成：铺底和声、低音、Karplus-Strong 拨弦（古筝感）、章节鼓点，随场景情绪变化，旁白出现时自动压低 |
| 地图 | Apache ECharts 4.9.0 自带的中国地图（含南海诸岛，Apache-2.0），由 `tools/build_map.py` 转成 `data/china_map.json` |
| 字体 | 思源宋体 / 思源黑体（Noto Serif SC / Noto Sans SC）、马善政楷书（Ma Shan Zheng），均为 SIL OFL，构建时从 Google Fonts 下载 |

```
script.json          旁白、画面文字、数据、镜头编排
data/china_map.json  中国地图 SVG 路径
web/                 渲染引擎（engine.js）与镜头模板（scenes.js）
tools/               narrate.py 旁白与时间轴 · music.py 配乐 · mix.py 混音
                     render.mjs 逐帧渲染 · mux.py 响度标准化与封装 · build.sh 一键构建
output/              成片与字幕
```
